## The max viable case I could get at 1024x2 is
24 stereo tracks with one FxmeNet plugin instance on each / All 17 FxmeFX plugins loaded in each FxmeNet instance / RME HDSP ASIO drivers FS=44100Hz Buffer=128
Server CPU at 55% on each core
Network charge at ~71Mbps*2
Reaper CPU usage below 20%
In this configuration I get concealed blocks sometimes (one every 5-10s)

At 28 stereo tracks, I get 1-2 concealed blocks per second

It has to be noted that at 24, and more often at 28, I get occasionnal peaks in the audio out, like a sudden dirac. Without this, one could eventually tolerate a few lost blocks, but these sounds are very annoying.
